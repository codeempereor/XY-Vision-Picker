> Version: v1.0
> Date: 2026-09-23
> Scope: 从物料采购 → 机械组装 → 固件烧录 → 视觉标定 → 全流程联调，可直接照做。

---

## 1. 项目概述

基于 **STM32F407ZGT6 + K210** 的两轴 X-Y 视觉识别抓取系统。K210 负责图像识别并输出目标像素坐标，STM32 负责运动控制与抓取执行，二者通过 UART 解耦；STM32 通过 CAN 与上位机交换状态。

| 项目 | 取值 |
|------|------|
| 主控 MCU | STM32F407ZGT6（168 MHz，HAL + FreeRTOS） |
| 视觉协处理器 | K210（MaixPy / MicroPython） |
| 摄像头 | OV2640 DVP 24pin，66° 视场 |
| 运动平台 | CoreXY 十字滑台（套餐2，含 2×42 步进电机） |
| 步进驱动 | DRV8825 ×2 |
| 末端执行 | MG90S 舵机 + 3D 打印多指夹爪 |
| 人机交互 | ST7789V SPI TFT + 4×4 矩阵键盘 |
| 限位 | 卧式微动开关 ×4 |
| 电源 | 24V/5A 主电源 + 5V USB 充电头 |

## 2. 系统架构

```
┌─────────────┐   UART 115200    ┌──────────────────┐   STEP/DIR   ┌──────────────┐
│ K210+OV2640 │ ───────────────> │                  │ ──────────>  │ DRV8825 ×2   │
│ (视觉识别)   │ <─────────────── │  STM32F407ZGT6   │             │ → CoreXY 滑台 │
└─────────────┘   (心跳/应答)     │  + FreeRTOS      │   PWM        └──────────────┘
                                   │                  │ ──────────>  MG90S 舵机
┌─────────────┐   SPI               │                  │   GPIO       ┌──────────────┐
│ ST7789V TFT │ <────────────────> │                  │ ──────────>  │ 4×4 矩阵键盘  │
└─────────────┘                    │                  │             └──────────────┘
                                   │                  │   CAN        ┌──────────────┐
                                   │                  │ ──────────>  │ TJA1050→上位机│
                                   └──────────────────┘             └──────────────┘
```

**分工原则**：
- K210 只输出 `(cx, cy, flag)` 像素坐标，不关心运动学。
- STM32 只接收目标坐标、做直线插补、驱动电机与舵机，不处理图像。
- 两者仅 UART 相连且必须 **共地**。

## 5. 机械组装要点

1. **CoreXY 框架水平放置**，四个脚垫调平，开机前手动推滑台确认全程无卡顿。
2. **电机与同步带张力**：用手指按压同步带，挠度约 5~8 mm 为宜，过松丢步，过紧发热。
3. **限位开关安装**：
   - 机械零位固定在 X-、Y- 两端；
   - 触发时滑台距导轨端部保留 ≥3 mm 缓冲；
   - 所有限位接线在断电状态下完成，避免误撞。
4. **K210 摄像头安装**：
   - 固定在滑台末端的支架上，光轴垂直于工作台面；
   - 视场覆盖整个工作区（约 200 mm × 150 mm）；
   - 加半透明遮光罩，避免环境光反射影响颜色阈值。
5. **MG90S 与夹爪**：舵机摇臂先手动转到中位再装夹爪连杆，避免上电瞬间冲击。

## 6. 通信协议

### 6.1 K210 ↔ STM32（UART，115200-8-N-1）

**K210 → STM32**，文本帧，`\n` 结尾：
```
$<X>,<Y>,<FLAG>\n
```
- `X, Y`：目标质心像素坐标，范围 `0..319, 0..239`（QVGA）；
- `FLAG`：`1` = 识别到目标，`0` = 未识别；
- 示例：`$128,96,1\n`

**STM32 → K210**（心跳 / 应答，可选）：
```
@<STATUS>\n
```
- `0` = 空闲可识别，`1` = 运动中忽略，`2` = 抓取完成。

> 速率约束：K210 端每 50~100 ms 发一帧即可，STM32 端用环形缓冲接收，避免阻塞运动任务。

### 6.2 STM32 ↔ 上位机（CAN 2.0B，500 kbps）

| 帧 ID | 方向 | 载荷（8 byte） |
|-------|------|----------------|
| 0x181 | STM32→PC | `pos_x(int16) pos_y(int16) status(uint8) reserved×3` |
| 0x281 | PC→STM32 | `cmd(uint8) param1(uint8) param2(uint8) reserved×5` |
| 0x381 | STM32→PC | 错误码 `err(uint16) info(uint16) reserved×4` |

`cmd` 取值：`0x01` 回零，`0x02` 手动移动，`0x03` 自动抓取，`0x04` 停止。

## 7. 视觉—运动学标定

开机后**首次必须标定**，步骤：

1. 滑台回机械零位（X-、Y- 限位触发点）。
2. 在工作台面放一张 A4 纸，打印一个已知坐标的网格点（如 `(20,20)`、`(60,60)`、`(100,100)`、`(140,100)`、`(180,20)`，单位 mm）。
3. K210 运行 `03_Firmware/K210/calibration/calib.py`，对每个标记点输出像素坐标。
4. 用最小二乘拟合仿射变换：
   ```
   [mm_x]   a  b  c   [px]
   [mm_y] = d  e  f × [py]
                      [1 ]
   ```
   得到 6 个系数，存入 STM32 内部 Flash（地址 `0x0800 FC00`，保留扇区）。
5. 验证：手动让 STM32 走到 3 个未参与拟合的点，误差应 ≤ ±1 mm；不达标重新标定。

## 8. STM32 软件结构（FreeRTOS）

| 任务 | 优先级 | 周期 | 职责 |
|------|:---:|------|------|
| `vCommTask` | 4 | 事件驱动 | UART1 收 K210 帧、CAN 收发；解析后用队列投坐标 |
| `vMotionTask` | 5（最高） | 事件驱动 | 取目标坐标 → 直线插补 → TIM 出脉冲 → 到位后控舵机 → 走投放点 → 松爪 |
| `vDisplayTask` | 2 | 50 ms | 刷新 TFT：当前坐标 / 模式 / 抓取计数 / 错误码 |
| `vKeyTask` | 3 | 20 ms | 扫描 4×4 键盘，短按切换模式，长按清零 |
| `vHeartbeatTask` | 1 | 1 s | PC13 LED 闪烁，CAN 心跳上报 |

**关键算法**：
- 直线插补：逐点比较法，按 `max(|dx|,|dy|)` 决定脉冲频率；
- 加减速：S 形曲线，起步/停止段各 200 ms，避免丢步；
- 限位保护：任何运动中检测到限位触发立即关闭 TIM 输出，发错误帧 0x381。

## 9. K210 软件结构

入口：`03_Firmware/K210/vision/main.py`

```python
import sensor, image, time, gc
from machine import UART

uart = UART(UART.UART1, 115200, timeout=1000)
sensor.reset()
sensor.set_pixformat(sensor.RGB565)
sensor.set_framesize(sensor.QVGA)   # 320x240
sensor.run(1)

# 阈值通过 MaixPy IDE 现场标定后写入
RED  = (30, 80, 30, 80, -20, 20)

while True:
    img = sensor.snapshot()
    blobs = img.find_blobs([RED], pixels_threshold=200, area_threshold=200, merge=True)
    if blobs:
        b = max(blobs, key=lambda x: x.pixels())
        cx, cy = b.cx(), b.cy()
        uart.write("$%d,%d,1\n" % (cx, cy))
    else:
        uart.write("$0,0,0\n")
    gc.collect()
    time.sleep_ms(80)
```

- 颜色阈值文件：`vision/thresholds.json`，多目标可扩展；
- YOLO 模型（可选）：`vision/yolo.kmodel`，识别稳定后替换 `find_blobs`。

## 10. 联调流程

按以下顺序，**每一步通过后再进行下一步**：

1. **单轴点动**：STM32 只发脉冲，X 轴走 100 mm 应平稳、无异响；记录 `脉冲数/毫米`。
2. **双轴联动**：矩形轨迹 100×80 mm，跑 5 圈无丢步、无累计偏差。
3. **舵机**：0°/90°/180° 三位置，夹爪开合到位、不抖动。
4. **K210 视觉**：固定颜色块在画面中移动，串口助手看到 `$cx,cy,1` 坐标实时跟随。
5. **UART 联调**：K210 发坐标，STM32 OLED 显示收到的 (mm_x, mm_y)。
6. **整链**：放一个红色方块在工作区，系统自动识别 → 移动 → 抓取 → 投放，连续 20 次成功率 ≥ 90%。
7. **CAN 联调**：上位机发 `0x03` 自动抓取命令，STM32 收到并启动流程。

## 11. 避坑清单（必须遵守）

- [ ] **MG90S 必须独立 5V 供电**，不要从 STM32 板载 5V 取；上电瞬间电流会拉低电压导致 MCU 复位。
- [ ] **K210 与 STM32 必须共地**，否则串口乱码。
- [ ] **DRV8825 细分固定 1/16**，电流参考电压 Vref 按电机额定电流设（通常 0.6~0.8 V），过高会烧电机。
- [ ] **限位开关上电后先测试**，触发时序必须正确，否则回零撞机械结构。
- [ ] **摄像头排线方向**：金手指朝向按 OV2640 模组丝印插入，反接无图像且可能损板。
- [ ] **环境光**：颜色阈值标定必须在实际工作光照下进行，LED 灯箱与自然光差异很大。
- [ ] **断电再接线**：所有接线（尤其电机相线、舵机线）必须在 24V 断电状态下插拔。
