# 上位机（mypro00001）角色、功能与适配说明

> 项目：XY_Vision_Picker
> 版本：v2.0 ｜ 日期：2026-10-09 ｜ 状态：已迁移、已编译验证
> 说明：本文档描述当前实际使用的 Qt 上位机（工程目录 `mypro00001/`）。旧文档《03_上位机模块开发文档.docx》（Qt 5.15 + 0x101 协议）为设计期初稿，协议与实现均已被本文档取代。

## 1. 上位机在项目中的角色

系统为三层架构，上位机只做 **PC 监控与命令层**，不参与实时闭环：

```
┌─────────────────┐   UART 115200   ┌──────────────────┐   CAN 500kbps   ┌──────────────────┐
│  K210 视觉识别   │ ──────────────► │  STM32F407 运动   │ ──────────────► │  PC 上位机（Qt）   │
│  OV2640 摄像头   │  $cx,cy,flag\n  │  FreeRTOS+CoreXY  │  0x181/0x281/   │  运动控制面板      │
│  颜色分割/质心   │                 │  步进电机+舵机    │  0x381          │  监控/命令/显示   │
└─────────────────┘                 └──────────────────┘                 └──────────────────┘
```

- **职责边界**：上位机负责 连接管理、命令下发（回零/手动/自动/停止/点动移动）、状态与坐标显示、错误告警、点阵字模预览。
- **独立性**：上位机断开不影响 STM32 本地运行（本地按键+OLED 仍可完成抓取流程），上位机只是"监控 + 手动操作入口"。

## 2. 功能清单

| 功能 | 说明 |
|---|---|
| CAN 连接 | QCanBus `peakcan` 插件，PEAK 兼容 USB-CAN 适配器，500 kbps |
| 命令下发 | 回零(0x01) / 手动模式(0x02) / 自动模式(0x03) / 停止(0x04) |
| 手动移动 | 输入 X/Y（mm，int16 小端），发送 0x06 手动移动命令，STM32 走直线插补 |
| 实时显示 | 位置上报(0x181)：pos_x/pos_y（0.001mm 单位）+ 状态（0空闲~6错误） |
| 错误显示 | 错误帧(0x381)：0x0001 限位急停 / 0x0002 越界 / 0x0003 超时 |
| 点阵预览 | 32×32 点阵字模可视化（纯显示，不参与 CAN 发送） |

## 3. 与 STM32 固件的协议适配

上位机协议与固件 `App/comm_can.c` 完全对齐：

| CAN ID | 方向 | 内容 |
|---|---|---|
| 0x181 | STM32 → PC | 上报：pos_x(int16 LE, 0.001mm) + pos_y(int16 LE) + status(u8) |
| 0x281 | PC → STM32 | 命令：d[0]=cmd（0x01回零/0x02手动/0x03自动/0x04停止/0x06手动移动）；cmd=0x06 时 d[1..2]=X(mm,int16 LE)、d[3..4]=Y(mm,int16 LE) |
| 0x381 | STM32 → PC | 错误：err(uint16 LE) |

- 状态枚举（固件 `app_config.h` / 上位机 `protocol.h` 一致）：0 空闲 / 1 回零 / 2 手动 / 3 自动 / 4 抓取 / 5 完成 / 6 错误。
- `0x06 手动移动` 为上位机开发时新增的固件协议扩展（`comm_can.c` 已实现），上位机输入毫米值 → 固件换算为步数并走 CoreXY 直线插补。

## 4. 工程位置与环境

| 项目 | 值 |
|---|---|
| 工程目录 | `F:\Projects\01_Embedded\STM32\XY_Vision_Picker\mypro00001\mypro00001\` |
| 主程序 | `main.cpp` / `mainwindow.cpp` / `mainwindow.h` / `protocol.h` / `dotmatrixview.cpp|h` |

| IDE | Qt Creator（`F:\Qt\Tools\QtCreator\bin\qtcreator.exe`） |
| Qt | Qt 6.11.0 MinGW 13.1 64 位（`F:\Qt\6.11.0\mingw_64`，需 SerialBus 模块） |
| CAN 插件 | `qtpeakcanbus.dll`（SerialBus 模块内） |

### 打开方式（Qt Creator）

1. 启动 Qt Creator：`F:\Qt\Tools\QtCreator\bin\qtcreator.exe`
2. File → Open File or Project → 选择 `F:\Projects\01_Embedded\STM32\XY_Vision_Picker\mypro00001\mypro00001\mypro00001.pro`
3. 选择构建套件（Qt 6.11.0 MinGW 64-bit），构建运行

### 运行前提

- 安装 PEAK 兼容驱动（`PEAK-System_Driver-Setup`，见项目根目录），插入 USB-CAN 适配器并拨码 120Ω 终端电阻
- 上位机连接前，STM32 侧 CAN 需已上电（固件已配置 CAN1 500kbps，PA11/PA12）

## 5. 与旧设计文档的差异

| 项 | 旧文档（03_上位机模块开发文档.docx） | 当前实现（mypro00001） |
|---|---|---|
| Qt 版本 | 5.15 LTS | 6.11.0 MinGW |
| 绘图 | QCustomPlot 实时轨迹 | 位置数字显示（无轨迹图） |
| 协议 | 0x101 心跳 / 0x102 位置 / 0x301 错误 / 0x302 完成 | 0x181 位置 / 0x281 命令（含 0x06 移动）/ 0x381 错误 |
| 点阵 | 无 | 32×32 点阵字模预览（纯显示） |
| 位置单位 | — | 0.001 mm（int16 LE） |

## 6. 后续演进建议

- 若需轨迹绘制：可复用 `qcustomplot` 或 QtCharts，订阅 0x181 帧绘制 X-Y 轨迹
- 若需参数下发：在 0x281 增加 cmd 扩展（如速度/加速度），固件 `comm_can.c` 同步扩展即可
- 若做自动流程展示：可读取 0x181 状态机枚举，按状态高亮"回零→识别→抓取→投放"流程
