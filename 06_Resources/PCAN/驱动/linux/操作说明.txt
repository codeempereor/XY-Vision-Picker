ubuntu系统上使用

(1) 需要确认安装好下面的相关库：

	# sudo apt-get install libpopt-dev
	# sudo apt install make
	# sudo apt install make-guile
	# sudo apt install gcc
	# sudo apt install g++
	# sudo apt install libpopt-dev

(2) 安装pcan驱动：

	# tar xvf peak-linux-driver-8.15.2.tar.gz
	# cd peak-linux-driver-8.15.2/
	# make clean
	# make
	# sudo make install 

	# pcaninfo		（接上板子之后，输入这个命令可以查看到pcan驱动和板子的信息）

boardcon@ubuntu20:~/opt/peak-linux-driver-8.15.2$ pcaninfo
PCAN driver version: 8.15.2
PCAN-Basic version: 4.6.2.36

  * pcanusb32: "PCAN_USBBUS1" (0x051), PCAN-USB #1, devid=0x00 (/sys/class/pcan/pcanusb32)


(3) 安装 pcanview:

	# wget -q http://www.peak-system.com/debian/dists/`lsb_release -cs`/peak-system.list -O- | sudo tee /etc/apt/sources.list.d/peak-system.list
	# wget -q http://www.peak-system.com/debian/dists/wheezy/peak-system.list -O- | sudo tee /etc/apt/sources.list.d/peak-system.list
	# wget -q http://www.peak-system.com/debian/peak-system-public-key.asc -O- | sudo apt-key add -
	# sudo apt-get update
	# sudo apt-get install pcanview-ncurses

	执行完上面的命令之后，pcanview 就安装成功了，可以查看到： 

	# ls /usr/bin/pcanview	

	# pcanview	(运行pcanview应用，设置好波特率后就可以收发数据了)
