## 本项目实际接线要点（依据联调记录）

- **驱动板供电**：电源模块 24V（V+/V- 各两个接线柱），经杜邦线引出接到驱动板 **VMOT** 与 **GND**；两路驱动板分别供电。
- **电流调节**：A4988 板上电位器调节电机电流，顺时针/逆时针限定最大输出；旋钮损坏会导致失去限位（曾出现电机不受控疯转，需更换驱动板或旋钮）。
- **拨码细分**：MS1~MS3 拨码设定步进细分（细分越大每转脉冲越多，速度越慢、越平稳）。
- **电机接线**：42 步进电机为两相四线（A+、A-、B+、B-），按驱动板 1A/1B/2A/2B 端对应连接；接反会导致电机只响不动或反向。
- **407 与驱动板信号**：STEP / DIR / ENA 由 STM32F407 定时器 PWM 引脚给出（具体引脚见 `03_Firmware/STM32` 固件与 CubeMX 配置文档）。
- **限位开关**：X- 限位接 **PA4**（高电平触发），Y- 限位接 **PD6**（低电平触发）。
- **CAN 通信**：407 开发板 CAN1 引脚 **PD0(RX)/PD1(TX)** 接 USB 转 CAN 适配器（UTC-T01）**CANH/CANL** 端子并共地 GND；适配器侧 120R 终端开关按总线两端情况拨动，上位机经 USB-CAN 监控。

> 完整接线文档见 `01_Docs/02_开发文档/10_硬件接线指南.docx`；排障过程见 `01_Docs/02_开发日志/`。
