# 数据手册索引

本目录存放本项目所用芯片/模块的官方数据手册。体积较大的手册保留在 `06_Resources/` 原始位置，本目录以索引说明为准。

## 芯片手册（原件位于 06_Resources/STM32F407ZET6/）

| 资料 | 文件 | 用途 |
|---|---|---|
| STM32F407 数据手册 | `06_Resources/STM32F407ZET6/STM32F407ZGT6.pdf` | 引脚定义、电气特性、封装 |
| STM32F4xx 中文参考手册 | `06_Resources/STM32F407ZET6/STM32F4xx中文参考手册.pdf` | 外设寄存器级编程（RCC/TIM/CAN/UART/GPIO） |
| Cortex-M4 内核编程手册 | `06_Resources/STM32F407ZET6/STM32F3与F4系列Cortex M4内核编程手册.pdf` | 内核指令、SysTick、异常向量 |
| 标准外设库用户手册 | `06_Resources/STM32F407ZET6/stm32f4xx_dsp_stdperiph_lib_um.chm` | 标准库 API 参考 |

## 板级资料（原件位于 06_Resources/STM32F407ZET6/）

| 资料 | 文件 | 用途 |
|---|---|---|
| GEC-M4 开发板原理图 | `06_Resources/STM32F407ZET6/GEC-M4原理图2016-07-29.pdf` | 开发板引脚排布、板载外设（已在 01_原理图 归档） |

## 摄像头手册（原件位于 06_Resources/YX64074-OV2640摄像头红版-190518/）

| 资料 | 位置 | 用途 |
|---|---|---|
| OV2640 摄像头模块原理图 | `4，OV2640参考资料/` 与 `1,OV2640摄像头模块原理图/` | 引脚定义与供电（已在 01_原理图 归档） |
| 摄像头配套软件/串口调试工具 | `3，配套软件/串口摄像头软件/` | 上位机预览与参数调试 |

> 补充说明：若后续采购替换型传感器（如 GY-31 颜色传感器、红外定位模块），对应数据手册按同样方式归档到本目录。
